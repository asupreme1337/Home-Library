# Домашняя библиотека

Настольное приложение для учёта книг и прочитанного. Учебная работа по дисциплине «Объектно-ориентированное программирование».

## Возможности

- Добавление, редактирование и удаление книг.
- Хранение названия, автора, жанра, года издания и количества страниц.
- Отметка о прочтении книги.
- Поиск по названию и автору без учёта регистра.
- Фильтрация по жанру и состоянию прочтения.
- Сортировка по названию, году и количеству страниц.
- Автоматическое сохранение каталога между запусками.
- Создание отчёта о сеансе при выходе.

## Установка и запуск

Для запуска нужны 64-разрядная Windows, Python 3.13 и библиотеки из `requirements.txt`. Интернет требуется только для установки зависимостей.

1. Установить [Python 3.13](https://www.python.org/downloads/windows/) с компонентами `pip` и Python Launcher.
2. Скачать проект через **Code → Download ZIP** и распаковать архив.
3. Открыть PowerShell в папке проекта и выполнить:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Для следующих запусков достаточно последней команды:

```powershell
.\.venv\Scripts\python.exe main.py
```

В VS Code можно открыть папку проекта и выбрать интерпретатор `.venv\Scripts\python.exe` через **Python: Select Interpreter**.

## Работа с программой

При входе нужно указать имя пользователя. Оно используется в отчёте о сеансе, пароль не требуется. При первом запуске в каталоге находятся 12 демонстрационных книг.

Кнопка «Добавить книгу» открывает форму заполнения. Жанр можно выбрать из списка или ввести самостоятельно. Название, автор и жанр обязательны, количество страниц должно быть положительным, а год — не больше текущего.

Чтобы изменить или удалить книгу, нужно выбрать строку в таблице. Двойной щелчок открывает редактирование. Отдельная кнопка меняет отметку о прочтении.

Поиск и фильтры работают совместно. Порядок книг задаётся списком сортировки и флажком «По убыванию». Внизу окна отображается количество найденных и прочитанных книг.

Изменения сохраняются автоматически. Завершить работу можно кнопкой «Выйти», крестиком окна или сочетанием Alt+F4. Если сохранить данные или отчёт не удалось, программа показывает сообщение об ошибке.

## Данные и отчёты

| Файл или папка | Назначение |
| --- | --- |
| `data/books_example.csv` | Демонстрационные книги для первого запуска |
| `data/books.csv` | Пользовательский каталог, создаётся автоматически |
| `reports/` | Текстовые отчёты о завершённых сеансах |

Каталог хранится в CSV в кодировке UTF-8. Удалённые книги не восстанавливаются при повторном запуске. В отчёте указываются имя пользователя, время входа и время выхода в формате `дд.мм.гггг чч:мм:сс`.

Программа должна находиться в папке с разрешением на запись, чтобы сохранять каталог и отчёты.

## Устройство программы

Интерфейс реализован с помощью PyQt6. Код разделён на несколько файлов:

| Файл | Содержимое |
| --- | --- |
| `main.py` | Запуск приложения и настройка интерфейса |
| `models.py` | Классы книг, каталога, маппинга и сеанса |
| `widgets.py` | Собственные компоненты интерфейса |
| `windows.py` | Главное окно, окно входа и форма книги |
| `requirements.txt` | Зависимости проекта |
| `tests/` | Проверки моделей и работы окон |

Основные классы:

- `Entity` — абстрактный базовый класс с методом описания объекта.
- `Book` — данные книги, проверка значений и сравнение объектов.
- `PairMap` — хранение пар «код — книга» на основе списка, без использования словаря.
- `Library` — работа с каталогом, поиск, сортировка, чтение и запись CSV.
- `Session` — имя пользователя, время работы и сохранение отчёта.

Предметные классы наследуются от `Entity`. Доступ к их атрибутам организован через свойства с геттерами и сеттерами. У объектов определены методы сравнения и строкового представления.
